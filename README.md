## About Me

I am a master's student at **Soochow University**, China. My research interests lie in **large language models (LLMs)** and **LLM-based agents**, particularly in using **tool dependency graphs** to guide tool selection, composition, and multi-step task execution.

I am also interested in long-horizon agent post-training and the long-context capabilities of language models.

## Research Interests

- **LLM Agents and Tool Use:** tool selection, function calling, and multi-tool composition
- **Graph-Guided Tool Planning:** tool dependency graphs and dependency-aware tool use
- **Long-Horizon Agents:** multi-step planning, decision-making, and agent post-training
- **Long-Context Language Models:** long-context understanding and reasoning
