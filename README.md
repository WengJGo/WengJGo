## About Me

I am a master's student at **Soochow University**, China. My research focuses on **large language models (LLMs)** and **LLM-based agents**, particularly the use of **tool dependency graphs** for tool selection, composition, and multi-step task execution.

My broader research interests include long-horizon agent post-training and long-context capabilities of language models.

## Research Interests

- **LLM Agents and Tool Use:** tool selection, function calling, and multi-tool composition
- **Graph-Guided Tool Planning:** tool dependency graphs and dependency-aware tool use
- **Long-Horizon Agents:** multi-step planning, decision-making, and agent post-training
- **Long-Context Language Models:** long-context understanding and reasoning
